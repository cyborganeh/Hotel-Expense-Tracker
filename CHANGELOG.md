# Changelog

## 0.1.0

- Added portable data-directory discovery with `HOTEL_DATA_DIR` support.
- Added demo and sample-data modes for dashboard previews.
- Added validation banners for missing folders and unsafe upload filenames.
- Added cached monthly reconciliation for local folder data.
- Added defensive parser, reconciliation, and exporter diagnostics.
- Added CLI `--version` / `-v` support.
- Added automated parser, reconciliation, export, and CLI smoke tests.
